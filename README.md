🍽️ **What's For Dinner? – Recipe Generator**

A responsive recipe discovery web application that helps users find meal inspiration by displaying random recipes.

Each recipe includes detailed information such as ingredients, step-by-step cooking instructions, preparation and cooking times, nutritional facts, difficulty level, cuisine type, and chef's tips.

**Features:**
- 🎲 Generate random recipes with one click.
- 🔄 Avoid displaying the same recipe twice in a row.
- ⭐ Display recipe ratings and reviews.
- 🥗 View ingredients and cooking instructions.
- 📊 Explore nutritional information.
- 👨‍🍳 Get useful chef's tips.
- 📱 Responsive design for different screen sizes.

**Technologies Used:**
- HTML5
- CSS3
- Bootstrap 5
- JavaScript (DOM Manipulation, Arrays, Objects, Functions, Template Literals)

**Goal:** Practice JavaScript fundamentals and DOM manipulation by building an interactive recipe generator.
